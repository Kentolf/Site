# Гайд по переводу в ВоГУ 

Сайт представляет собой пошаговое руководство для студентов, желающих перевестись в Вологодский государственный университет

## Ссылка на проект
Сайт доступен по адресу: [https://kentolf.github.io/Site/](https://kentolf.github.io/Site/)

index.html - Главная страница

conditions.html - Описание процесса и этапов отчисления/зачисления

documents.html - Список необходимых документов с образцами

faq.html - Ответы на популярные вопросы.
  
author.html - Информация об авторе.
  
style.css - Единый файл стилей для всего проекта
